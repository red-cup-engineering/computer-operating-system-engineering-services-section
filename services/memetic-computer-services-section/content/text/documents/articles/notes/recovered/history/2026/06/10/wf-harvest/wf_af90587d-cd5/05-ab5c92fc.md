# Boundary design for @emsenn/meme-topology — app-consumer persona (shell/REPL: articulate, settle, render)

Grounded in: /home/emsenn/561-group/lib/meme-topology/src/meme-topology.mts (keystone), src/meme-topology-fixed-point-reading.mts (readings/information), src/index.mts (current blanket barrel), package.json exports map, and the four survey reports.

## 1. Entrypoint structure: one curated root + four theory subpaths, blanket barrel deleted

An app should import exactly one module. Argument:

- The tests already treat the barrel as the boundary (all three test files import only `./index.mjs`); the 13-subpath map is dead weight that tests never exercise and that omits 9 of 22 modules anyway. The subpath map currently *communicates* a boundary the barrel doesn't *enforce* — worst of both worlds.
- A REPL author must never face ~850 flat names where `judgment`, `divide`, `present`, `bottom`, `dual`, `rank`, `Witness` collide with their own vocabulary. Curated root kills the collision surface for the 75-package rebuild.
- But the math layers must stay reachable for power consumers (the daemon persona, future agents) without re-opening the barrel. Subpaths are the escape hatch with a deliberate cost: importing one is a visible decision in the consumer's source.

Proposed exports map:

```
"."           → curated app surface (~60 names, section 2)   ← the ONLY thing apps touch
"./theory"    → typed-theory: theoryOfBase, derive, checkDerivation, judgment(→typing), proof carriers
"./algebra"   → bilattice-charge + bilattice-linear-logic + bilattice-relation (full lawful algebra)
"./dynamics"  → ordinal-closure, predication-settling, predication-firing, predication-cohomology,
                substitution-dynamics, spectral (regime/cohomology/spectral vocabulary)
"./number"    → exact-number (full arithmetic)
```

`src/index.mts` stops star-exporting; it becomes the curated root. The 9 currently-subpathless modules get NO subpath and are dropped from index: they become internal (section 3). `sideEffects:false` and `files:[dist]` stay as-is.

## 2. Public vocabulary at the root, by category (old → new)

### A. Articulation (strings in, frozen carriers out)
- `mark`, `token`, `claim`, `utterance`, `articulate` — keep names. **`Mark`/`Token`/`Claim` classes → frozen-object factories** (the only classes in an otherwise frozen-POJO algebra; tests already use only the factories, never the classes). Export the types, not constructors-as-classes.
- `cell`, `predicate`, `specializationMorphism`, `predicationCarrier`, `cohere` — keep.
- `unrelatedPairs` → returns named `UnrelatedPairsCarrier` (today it's the library's only anonymous inline carrier type).

### B. Admission (the input side of induce)
- `Witness` (predication-fiber.mts:33) → **`Attestation`**. Reserving "Witness" for judgment-affirmatives is non-negotiable: `induce(witnesses: readonly Witness[])` currently invites a fresh agent to pass judgment carriers. (Naming report rule K6.)
- `witnessCarrier` → **`attest(predication: Cell | SpecializationMorphism, options?): Attestation`**.
- `witnessedPotential` → NOT exported at root (see section 3 — it is the reason `stable`/`active` are unreachable; polarity must flow through `affirm`/`deny`, section 4).

### C. Settling (one call)
- `induce(attestations) → MemeTopologyCarrier` — keep, the keystone. One call gets fixed points, readings, settling, cohomology, theory, proofs.
- `singleUtteranceTopology`, `settleOneTraced`, `SingleUtteranceInput` — keep (REPL demo path).
- `knowledgeLeastMemeOfSingleUtterance` → fold into `settleOneTraced` result or drop; its body is a fragile `fibers[0]!.assignments[0]!` chain no app should imitate.
- `classifySettling`, `SettlingClassification` — keep at root (cheap regime read for a status line).
- Migration aliases documented, not exported: settle = knowledgeLeast, brim = knowledgeGreatest, adjudicate = truthLeast, presume = truthGreatest.

### D. Reading (the output side — what the REPL renders)
- `fixedPointReadingsOfWitnesses` → **`fixedPointReadingsOf(attestations)`**; `readCharge(reading, cell)` — keep.
- `MemeTopologyFixedPointReading(s)`, `MemeTopologyInformation`, `MemeTopologyInformationEntry` — keep; entries (`point`, `state`, `value`) are exactly what a section renderer iterates.
- `valuationConsistency` carrier type (reached as `reading.information.valuationConsistency`) — type exported, constructor internal.
- Gap reads: `fixedPointKnowledgeGap`, `fixedPointTruthGap` + `FixedPointGapCarrier` — keep ("ambiguity is the gap" is a first-class app feature).

### E. Charge vocabulary (rendering and comparison)
- `chargeValue`, `chargeValueName`, `asChargeValueName`, `chargeValues`, `ChargeValueName` ("absurd"|"potential"|"active"|"stable") — keep; this is the app's string boundary.
- Value-level algebra only: `joinKnowledgeValue`, `meetKnowledgeValue`, `joinTruthValue`, `meetTruthValue`, `negateValue`, `conflateValue` — keep (tests use only these; the carrier-level join/meet/leq are untested and go to `./algebra`).
- `sameChargeValue` → **`chargeValueIdentity(a, b): ChargeValueIdentityWitness | ChargeValueIdentityObstruction`** (house discipline: no bare booleans in judgment position). Apps match `.kind`.

### F. Numbers at the edge
- `toCount`, `fromCount`, `toNumber`, `toInt`, `fromInt` only — enough to render ranks and depths. Full arithmetic lives at `./number`.

Cross-cutting renames (apply at every layer, per the naming report): judgment unions standardize on `<Subject>Judgment` with `<Subject>Witness`/`<Subject>Obstruction` halves; `RelationReadAbsence`/`RelationMatrixEntryAbsence` → `...Obstruction`; kind strings adopt camelCase atoms with `:witness` / `-obstruction` tails (`predication.valuation.fixedPoint:witness`), a mechanical two-site-per-kind edit.

## 4. What is MISSING for the app persona (specific signatures)

**(a) Polar admission — the blocker.** Through `induce` today every cell seeds at `witnessedPotential(c.subject)` (meme-topology.mts:42): `active` and `stable` are unreachable via the keystone, so the library's central promise (stable = held contradiction) cannot be demonstrated in a REPL at all. Also the boxed evidence is the cell's own subject — audit-useless.

```ts
type TermInput = string | Mark;
interface AttestOptions { readonly provenance?: unknown }   // opaque, frozen, never inspected by the kernel
interface Attestation {
  readonly kind: "meme-topology.attestation";
  readonly predication: Cell | SpecializationMorphism;
  readonly polarity: "affirm" | "deny";
  readonly provenance?: unknown;
}
function affirm(subject: TermInput, predicate: TermInput, object?: TermInput, options?: AttestOptions): Attestation;
function deny(subject: TermInput, predicate: TermInput, object?: TermInput, options?: AttestOptions): Attestation;
function specializes(special: TermInput, general: TermInput, options?: AttestOptions): Attestation;
```

`induce` seeds affirm→potential, deny→active; affirm+deny of one cell knowledge-joins to stable — the held contradiction, never an error. These subsume the mark→token/claim→cell plumbing no app should hand-write (the `tm`/`cl` sugar both test files define locally is the proof of demand).

**(b) Value-level section reads.** Today `readCharge` needs a constructed Cell, and enumeration means walking `reading.extremum.sheaf.section.fibers[].assignments[]`.

```ts
function chargeNameAt(reading: MemeTopologyFixedPointReading, subject: TermInput, predicate: TermInput, object?: TermInput): ChargeValueName;
function predicationsFor(reading: MemeTopologyFixedPointReading, subject: TermInput): readonly MemeTopologyInformationEntry[];
function subjectsFor(reading: MemeTopologyFixedPointReading, predicate: TermInput): readonly MemeTopologyInformationEntry[];
```

**(c) The canonical four-way partition** that language-generation, news, web-swarm-gui, and profiling each re-derive today:

```ts
interface SectionPartitionCarrier {
  readonly kind: "meme-topology.sectionPartition";
  readonly affirmed: readonly MemeTopologyInformationEntry[];     // active
  readonly denied: readonly MemeTopologyInformationEntry[];       // (truth-order dual)
  readonly undetermined: readonly MemeTopologyInformationEntry[]; // absurd/potential residue
  readonly contradicted: readonly MemeTopologyInformationEntry[]; // stable — held, rendered, never thrown
}
function partitionSection(reading: MemeTopologyFixedPointReading): SectionPartitionCarrier;
```

**(d) Incremental re-settle for an interactive loop** (sound because evidence is monotone — re-closing from the previous fixed point seeded with the delta is valid):

```ts
function extend(carrier: MemeTopologyCarrier, delta: readonly Attestation[]): MemeTopologyCarrier;
```

Even if v1 is `induce([...carrier.witnesses, ...delta])` internally, the name belongs on the boundary so daemons and REPLs target it now and optimization lands later without a breaking change.

**(e) Session persistence.** Carriers contain bigint-backed exact numbers; `meme-topology-addressing` throws on bigint, so today nothing crosses a process boundary or a REPL save-file:

```ts
function dehydrateAttestations(attestations: readonly Attestation[]): JsonValue;  // exact numbers as decimal strings
function rehydrateAttestations(value: JsonValue): readonly Attestation[];
```

Attestation-log persistence + re-induce is the sound event-sourced shape; carriers themselves need no serializer.

**(f) Status-line counts** so a prompt can show `12 cells · 1 contradiction · regime: finite` without fiber-walking:

```ts
function sectionCounts(carrier: MemeTopologyCarrier): {
  readonly kind: "meme-topology.sectionCounts";
  readonly cells: Natural; readonly contradictions: Natural; readonly residue: Natural;
  readonly regime: SettlingClassification["regime"];
};
```

## 5. Consumer contract (README header)

You speak to this library through three verbs: `affirm`/`deny` (and `specializes`) turn plain values into attestations, `induce`/`extend` settle them into a frozen MemeTopologyCarrier, and the reading functions (`chargeNameAt`, `predicationsFor`, `partitionSection`) render any of the four fixed-point sections. Every judgment returns a witness-or-obstruction carrier you match on `.kind` — never a boolean, and never an exception for a domain outcome; throws mean only malformed input. A `stable` charge is a held contradiction and a normal answer: render it, never treat it as an error, and never construct it by hand. Evidence is monotone (attesting more can only raise knowledge), the knowledge and truth orders are independent (never mix their joins), all arithmetic is exact, and all carriers are deeply frozen. Import only the package root; the `./theory`, `./algebra`, `./dynamics`, and `./number` subpaths are the underlying mathematics, and anything not exported from them is internal because calling it can assemble carriers that violate these invariants.
