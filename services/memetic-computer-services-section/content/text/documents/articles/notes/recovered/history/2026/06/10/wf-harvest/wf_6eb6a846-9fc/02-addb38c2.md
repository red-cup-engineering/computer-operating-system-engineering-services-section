# Daemon Precedent Survey — patterns to keep, habits to reject

## 1. services/newswire — NewswireService tick loop + HTTP app

Files: `/home/emsenn/561-group/services/newswire/src/index.mts` (lines 840-944: `NewswireService`), `/home/emsenn/561-group/services/newswire/src/cli.mts`.

**Keep:**
- **tick() as a pure, separately invokable unit** — `tick(): Promise<Newswire>` does one full ingest→derive cycle and returns the new world; `start()` merely schedules it. The CLI's `--once` flag (cli.mts:56-59) runs one tick and prints the snapshot — exactly the shape an ordinal-advance daemon wants: a tick is callable as a function, the scheduler is detachable policy.
- **Reentrancy guard returning the current world** (index.mts:865: `if (this.#running && this.#current !== null) return this.#current;`) — overlapping ticks collapse to the standing fixed point rather than queueing or erroring.
- **The world is rebuilt whole and immutably each tick** — `#current = newswireFromClaimSets(...)`; all derived surfaces (feeds, sitemaps, pages, ninjs artifacts, gate audit) are frozen projections of one value. fold(log)-shaped even though the log lives elsewhere.
- **Live `get resources()` over the current world** (index.mts:855-861) plus an explicit **unavailable resource at 503 before first settlement** (`#unavailableResource`) — the HTTP app is a window onto whatever has settled, including "nothing yet," and the snapshot endpoint serves 503 while `lastError` stands. Honest degraded states, no fake data.
- **`/newswire-service.json` snapshot endpoint** — kind-tagged (`"newswire.service.snapshot"`), counts runs, exposes lastError. Keep the introspection endpoint; rework its content (below).
- **Admission validation at the boundary** — `assertClaimSets`/`assertClaim` (index.mts:824-838, 946-956) type-check every inbound record with a path-addressed error before it enters. The skeleton of a provenance gate (though it only checks shape, not witness).
- **The audit surface as first-class output** — `newswire-audit.json` with `contested` counted per gate (index.mts:729-737): contradiction rendered as a declared audit reading, not suppressed. This is the calm/audit pair already half-built.
- **CLI ergonomics**: config-from-manifest (`561:newswire` key in package.json), env/flag layering, injectable io/`fetchImpl`/`startServer` for tests, `installGracefulShutdown(result, { onClosed: () => service.stop() })`.

**Reject:**
- **`setInterval` as the engine** (index.mts:883-890): wall-clock intervals *drive* the tick. For the daemon, ticks must be witness-driven ordinal advances; a timer may at most *generate witnesses* ("poll conduit X observed at T") that the engine admits like any other evidence. `intervalSeconds`/`intervalMs` config baked into the instance shape is the same habit.
- **`new Date().toISOString()` as run identity** (`#lastRunAt`, index.mts:872; also settling-orbit's `now` default) — wall-clock used as sequencing/state rather than witnessed testimony. The daemon's run counter should be the settling ordinal; wall-clock readings are data cells with provenance.
- **Mutable private-field state machine** (`#runs`, `#lastError`, `#current`) — service history lives in fields that vanish on restart. Errors are swallowed (`void this.tick().catch(() => {})`) leaving only the last message. Everything-is-a-trace says: runs, errors, and admissions are witnesses appended to the daemon's own log; the snapshot is fold(log).
- **Single-observer, full-replace semantics**: each tick fetches *one* upstream URL and replaces the world wholesale — no accumulation, no multi-source merge, no memory of prior claims. The classical degenerate case baked into the API (`newsroomClaimSetsUrl: string`, singular).
- **`pubStatus: "usable"` hardcoded** (index.mts:463) — a boolean-ish collapse of a settleable status performed inside the carrier, not at a declared rendering edge.

## 2. swarm-intelligence mini-daemon — the working descent pipeline

Files: `/home/emsenn/561-group/lib/research/triage/2026/05/26/swarm-intelligence/scripts/swarm.mjs`; sheafing at `.../positing/library/scott-continuous-posit-category/sheafing/scripts/sheafing.mjs`; settling-orbit at `.../settling/library/settling-orbit/scripts/settling-orbit.mjs`; trace/appending schemas under `.../settling/library/finite-settlement-algebra/`.

**Keep:**
- **The whole pipeline as gerunds**: decoding → inferring (one call per observer endpoint) → sheafing → articulating → predicating → settling → folding. Each stage is a pure module; the daemon is just the composition run persistently. This is "programs are evidence" already operational.
- **Observers as peers, consensus as cohomology** (sheafing.mjs): H0 per connected component = knowledge-*join* (idempotent ⇒ count-independent) plus knowledge-*meet* for what's common; H1 = first Betti number of the truth-opposition subgraph — exact on a 1-complex, not a heuristic. `coordinationFree = (obstruction === 0)` computes whether consensus needs coordination instead of arguing about it (Way 8/CALM). The distinction that evidence-gaps and absorptions are coboundary-absorbable while only active-vs-stable opposition obstructs — keep verbatim.
- **TTAM on-disk settling**: URI = path (`subjectUri = join(ROOT, slug)`; `subject = { $ref: subjectUri }`), each subject owns its JSONL log (`<root>/<slug>/<slug>.jsonl`), rows are EAVT/SPOT (settling-orbit: A = the settling generator, E = subject, V = settled charge, T = transaction), the trace schema is path + G-Set of canonical row ids, appending is declared monotone/idempotent-on-duplicate-id. Belief is read back by **folding the subject's own log** (swarm.mjs:74), never from in-memory residue. "At rest it is the topology on disk; running, it is the flow" — this is the proof of concept.
- **Settling-orbit honesty about fuel**: bounded fuel that stops early returns `regime: "partial-prefix"`, *never* reported as final settlement; `fixedPoint` only when all increments folded. The daemon's incremental settling API should preserve this regime-tagged result shape.
- **Witnessing only URI-addressed subjects** (settling-orbit: `if (uriOf(entry.cell.subject) === null) continue;`) — no address, no durable world. Crude but the right instinct; the daemon should quarantine rather than skip.
- **Charge rendered at the edge**: `belief = CONTESTED | AFFIRMED | DENIED | UNSETTLED` computed only at stdout, from the folded bilattice value — the carrier never holds the collapsed word.

**Reject:**
- **One-shot process, exit codes as protocol** (exit 2/3/4): the run leaves stderr commentary and a final fold but the *pipeline events themselves* (which observers answered, what sheafing computed, H1 value) are not appended as witnesses — only the settled value is. The daemon must trace the observation acts too.
- **`now: new Date().toISOString()` as the transaction T** — wall-clock as the transaction identity rather than an ordinal with wall-clock as witnessed payload.
- **Regex decode of observer replies to a fixed 3-way charge** (`/\byes\b/` → affirms) — a codec with undeclared loss; fine as scaffold, but the daemon's conduits must be declared codecs reporting residue.
- **Aspirational imports**: `#script/settling`, `#script/articulating`, `#script/predicating`, `#folding` (→ `scripts/folding.mjs`), and the entire `agentic-orchestration-platform` tick/heartbeat/dispatch/federation subtree exist in the package.json imports map but **the files are absent** (appending/merging/querying-trace `scripts/` dirs are empty). swarm.mjs as committed cannot run. Treat the tree as a design document plus a working sheafing/settling-orbit core, not a runnable daemon. Do not inherit the 12-deep `library/.../library/` path liturgy into a service layout.
- **Hardwired observer list** (`ENDPOINTS = [...]` in the script) — observers should be admitted/withdrawn as witnessed facts, not source constants.

## 3. lib/posix-holography/src/fs — the persistence floor

Files: `/home/emsenn/561-group/lib/posix-holography/src/fs/store.mts`, `flatfile.mts`, `address.mts` (also `eavt-log.mts`).

**Keep — this is the strongest code surveyed; adopt nearly wholesale:**
- **flatfile durability contract**: canonical bytes on disk (identity bytes = stored bytes), O_APPEND single-line atomicity, fsync-before-resolve, per-path in-process append queue that a failed append never poisons, torn-final-line tolerance on read (skip, never throw), ENOENT reads as `[]`. Append-only G-Set; no overwrite path exists in the API at all — Way 2 enforced by construction.
- **address codec**: term ↔ path is a pure reversible injective codec (`sanitizeSegment`/`desanitizeSegment` exact inverses, traversal-safe), `<root>/<segs...>/<leaf>.<ext>` with the leaf repeated so directory and log are both addressable, `termOf` as the inverse. No separate index — the path IS the address (Way 6). Plus `resolveAddress` with capability-gated access (`guardAccess`) — the embryo of provenance-gated address resolution for the daemon's address space.
- **Store discipline**: `persist` returns `null` for a meme with no witnesses — *nothing without a witness is ever written* (store.mts:21-27). `load` returns un-folded memes one-per-datom and the comment says folding "is the processing unit's job, not the store's" — strict store/settle separation the daemon must keep.

**Reject / supersede:**
- `persist` loops `await appendFlatfile` per datom — fine at this scale, but the daemon needs batched appends under one transaction witness so a crash can't admit half an observation as separately-settled rows (the flatfile only protects single lines).
- Whole-file `readFile` in `readFlatfile` — no streaming/offset resume; incompatible with incremental settling over a growing stream. The daemon needs a cursor (byte offset or row-id high-water mark) that is itself a witnessed cell.

## 4. services/memetics — MemeTrace and the actuation loop

Files: `/home/emsenn/561-group/services/memetics/src/trace.mts`, `service.mts`, `system.mts`.

**Keep:**
- **Immutable value-semantics trace**: `MemeTrace.append()` returns a new trace; `observe/potential/active/stable` are charge-explicit appenders; datoms are 5-tuples `[point, state, value, witness, charge]` with the **witness a mandatory positional argument** — you cannot construct an observation without one. Content-derived identity: `id = termKey(["memetics.trace", datoms.map(traceDatomKey)])`, address derived as `logPath(root, term)`.
- **Quiescence by signature comparison, not flag**: `actuateSystem` compares sorted information signatures before/after; `quiesced` is a computed property of the world (service.mts:29-51).
- **`run()` = iterate-until-quiesced with maxSteps, returning `{ steps, quiesced }`** honestly — same partial-prefix honesty as settling-orbit, and `system.step` increments only on `withInformation` — **a step is an information-change ordinal, not a clock event**. This is the only precedent whose "time" is already correct. Zero wall-clock anywhere in the package.
- Permissive `of()`/load coercion (trace | input | bare datom iterable) at the boundary, strict immutability inside.

**Reject:**
- **The system is memoryless across runs**: `MemeticsSystem` holds traces in a Map, nothing touches disk — the holography Store and this loop were never joined. The daemon is precisely that junction.
- **`actuateSystem` recomputes all information for all traces every step** — full recomputation per tick; needs the incremental settling surface Wave 1 demands.
- **No provenance gate**: `TraceWitness` is carried but never *checked* — any caller can mint datoms with any witness string. Admission must verify the causal path, not just require the field.
- `DEFAULT_TRACE_ROOT = "/memetics"` — an absolute default root baked into the lib.

## Synthesis for the Wave 1 daemon design

Composite skeleton, each organ from the precedent that does it best:

- **Persistence floor**: posix-holography flatfile + address codec (canonical bytes, append-only, term=path, capability-gated resolve) + per-subject JSONL logs from the swarm TTAM. Add: batched transactional append, streaming/cursor reads.
- **Engine step**: memetics' signature-quiescence loop + settling-orbit's regime-tagged fixed-point result (`strict-finite` vs `partial-prefix`), made incremental (resume from valuation + cursor, per the journal's incremental-settling demand).
- **Multi-observer merge**: sheafing's H0 join/meet + H1 Betti obstruction as the consensus organ; `coordinationFree` exposed as a reading so coordination cost is computed, not assumed.
- **Service shell**: newswire's separable `tick()` / `--once` / snapshot-endpoint / live-resources / graceful-shutdown / honest-503 shape — but `tick()` becomes "admit pending witnesses, advance the settling ordinal," the scheduler becomes one optional witness-generating conduit among many (timer, fs-watch, HTTP POST of witnesses, webhook), and the snapshot becomes a reading over the daemon's own trace (Way 9: the daemon's runs/errors/admissions are cells in the substrate it settles).
- **Renderings**: charge words (CONTESTED/AFFIRMED/...) and booleans only at declared calm/audit surfaces (swarm.mjs stdout, newswire audit endpoint show the pattern); never in carriers or wire types.

Habits to reject, consolidated: `setInterval` as engine; `Date.now()`/ISO-now as sequencing, run identity, or transaction T (wall-clock is admissible only as witnessed payload); mutable in-field service history instead of self-trace; single-upstream full-replace worlds; shape-only validation standing in for provenance verification; hardcoded observer/endpoint lists; collapse-to-classical (`pubStatus: "usable"`, yes/no regex) inside carriers; imports-map aspirational files presented as working code; full recomputation disguised as a tick.

One doctrinal flag from `/home/emsenn/561-group/dev/docs/explanations/the-descent-as-cosmogony.md`: every precedent's charge type is FOUR-shaped (memetics' `"potential" | "active" | "stable"`, swarm's affirms/denies/abstains). The daemon's wire and storage shapes must carry the general residuated charge with FOUR as the named finite projection — widening later must be additive, not a rewrite. Also note its temporal-2-category reading: newswire's linear `#runs` counter is the strict-regime shadow; the daemon's ordinal should be carried as a term (admitting `α + β` advances), not a bare integer.
