Individual entry points: `knowledgeLeastFixedPoint(p)`, `knowledgeGreatestFixedPoint(p)`, `truthLeastFixedPoint(p)`, `truthGreatestFixedPoint(p)`. Greatest bounds seeded by `greatestSeedValuation(freeFalsity)` filling unevidenced sides with `present`/`absent`.

**Reading layer** (`meme-topology-fixed-point-reading.mts`): `fixedPointReadings(fixed): MemeTopologyFixedPointReadings` = 4 of `MemeTopologyFixedPointReading { order, bound, extremum, cohomology: CohomologyCarrier, information: MemeTopologyInformation }`. `MemeTopologyInformation` = `{ points: EntitySet, states: PredicateSet, entryCarrier (entries of {point, state, value: ChargeValue} knowledge-joined per (point,state)), relationMatrix, relation, valuationConsistency }`. **Gap** (`predication-valuation-fixed-point-gap.mts`): `fixedPointGap(fixedPointGapInput(order)): FixedPointGapCarrier` — per-cell least-vs-greatest comparison into `cellClosure:witness` / `cellOpening-obstruction` / `cellMissingGreatest-obstruction`, carriers `closures/openings/missingGreatest/obstructions` each with `rank: Natural`, and `vanishing: FixedPointGapVanishingJudgment`.

**Settling** (`predication-settling.mts`): `SettlingCarrier { stages: readonly SettlingStage[], cofinality }`; stage = `{ ordinal: SettlingStageOrdinalCarrier, shape: initial|successor|limit, designated: CellSet }`, monotone (constructor `settling(stages, cofinality?)` throws if a stage drops cells). ## How a long-lived process would use it today, and what's missing

Today's loop: hold `attestations: Attestation[]` in memory; on each new witness batch call `extend(carrier, delta)` — which is `induce` over the whole concatenation. Missing for incremental use:

1. **No incremental re-settling.** `extend` recomputes the entire world: rebuilds `predicationCarrier` base, re-runs all four closures from seed ordinal zero, recomputes 4× (cohomology + information matrix + consistency), settling, theory, proofs. The mathematically honest warm-start exists *almost*: `predicationValuationClosureProcess(order: PredicationValuationClosureOrderCarrier, seed: Valuation)` and `closePredicationValuationClosure(process)` are exported, so a daemon could seed the knowledge-least closure from the previous fixed point joined with the delta — but there is no helper to (a) extend a `PredicationCarrier` base with new terms, (b) merge delta memes into an existing `Valuation` (`composeFibers(memes, base)` rebuilds from a full meme list), or (c) splice the resulting orbit onto the previous `SettlingCarrier` so stage ordinals keep accumulating instead of restarting at `zeroOrdinal()`. Ticks restart at 0 every induce — the carrier has no memory that it is stage n of a longer descent.
2. **No diff/subscription surface.** Only `settlingClosureEquivalence` compares two worlds; nothing reports which cells changed charge between `carrier` and `extend(carrier, delta)`.
3. **No serialization at all in the lib.** `Mark`/`Token`/`Claim` are classes (`mark(value: unknown)`, prototype lost on JSON round-trip; `markOf` rejects plain objects); `LimitOrdinal.fundamentalSequence` is a function; carriers are deeply frozen cyclic-ish object graphs with no codecs/toJSON. The only persistence-compatible object is the `Attestation` log itself (`predication` + `polarity` + opaque `provenance`) — replay-by-`induce` is the storage story, which fits "everything is a trace / programs are evidence," but an Attestation codec (Cell/Mark encode-decode) does not exist anywhere yet.
4. **Provenance not enforced.** `provenance?: unknown` is optional; "no witness no world" gating is the caller's job.
5. **Cost profile is workbench-scale, not daemon-scale**: pervasive O(n²) linear scans (`findIndex` + coincidence predicates) in information entries, gap pairing, cohomology entity indexing.
