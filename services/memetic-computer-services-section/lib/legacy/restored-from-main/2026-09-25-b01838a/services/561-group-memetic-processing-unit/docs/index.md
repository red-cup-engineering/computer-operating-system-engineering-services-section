# Documentation

This directory documents `@561-group/memetic-processing-unit`, the processing layer that consumes the shared meme vocabulary and computes with it.

The package has two main faces:

- a stateful `Mpu` facade for accretive witness logging and projection queries;
- functional modules for charge algebra, descent, composition, modal closure, cone duals, and void reads. The general mathematics (Chu duality, exact arithmetic, closure ordinals, obstruction/cohomology, d-frame, spectral, Verdier) is `@lenticule-science/metrologic`'s and is imported from it directly.
