# Documentation

This directory documents `@561-group/meme`, the vocabulary package for the Meme and its descent vocabulary.

The package is small on purpose. It defines TypeScript types, shallow type guards, JSON Schemas, and type-only morphism signatures. It does not implement the memetic processing runtime.
